Introduction

MOVIRA PLC ("MOVIRA," "we," "us," or "our") publishes Coffee Runner: The Heart of Ethiopia ("Coffee Runner," "the app," or "the game"), an endless-runner game for Android, and the companion website that hosts it. This Privacy Policy explains, in plain language, what information the app and website handle, why, and what choices you have.

We wrote this policy directly from the app's actual source code and configuration rather than from a generic template. Where something couldn't be verified from the project files we had access to, we've marked it clearly instead of guessing — see the callout boxes marked "To confirm" throughout.

By downloading, installing, or playing Coffee Runner, or by visiting the companion website, you agree to the practices described here.

03

Information the application collects

Coffee Runner is built to run entirely on your device — as a browser-based 3D game that also installs and plays offline. Based on the project's source code, it does not include any code that transmits personal information to MOVIRA's servers, because MOVIRA does not operate a backend server, database, or API for the game. The only information that can reach us at all is:

  • Information you choose to send us. If you email our support address, we receive your email address, whatever name you send it under, and the content of your message.
  • Limited technical data handled automatically by the web platform as part of loading any web page or app, described in Sections 5–7.

We do not ask you to create an account, enter your name, or grant any sensitive device permission to start playing.

04

Information that is NOT collected

To be explicit, Coffee Runner does not collect, request, or have access to any of the following:

  • Your name, phone number, home address, or government ID
  • Precise GPS location
  • Camera, microphone, contacts, photos, or files on your device
  • Payment card details or billing information
  • Account passwords or login credentials (the game has no account system — see Section 9)
  • An advertising ID used to build an ad profile (no advertising SDK is present — see Section 11)

This list reflects what we found by inspecting the game's actual dependencies and code — not a boilerplate assumption.

05

Automatically collected technical information

Like any modern web-based game, Coffee Runner reads some basic technical characteristics of your browser and device — for example, screen size, general performance capability, and input type (touch vs. keyboard). The game uses this locally, in real time, to decide things like rendering resolution and control scheme so it runs smoothly on your specific device.

This technical data is processed on your device by the game itself and is not transmitted to MOVIRA PLC, because the app has no analytics pipeline or server to send it to.

06

Device information

The same applies to broader device information (such as browser type or general device class): where the game reads it, it's used only to adapt gameplay and visuals on-device, and it is not logged, stored, or sent anywhere by MOVIRA.

07

IP address / approximate location

MOVIRA PLC does not run its own servers for Coffee Runner and does not itself log, collect, or process your IP address.

That said, like visiting any website, delivering the game's files necessarily passes through infrastructure MOVIRA doesn't operate:

  • The website and game files are hosted by GitHub Pages, which — as a normal function of serving any web page — receives the requesting device's IP address.
  • The on-screen typeface is retrieved from Google Fonts, which likewise receives the IP address needed to deliver the font file (see Section 12).

Neither of these is something MOVIRA requests, stores, or has access to — it's an unavoidable part of how any website is delivered over the internet, disclosed here for transparency. Google's and GitHub's own privacy policies govern how they handle this technical data.

08

Game progress and locally stored data

Your progress — profile, missions, achievements, rank, and settings such as audio, controls, and language — is saved directly on your device, in two alternating, checksummed save slots designed so an interrupted write can't corrupt your progress. This save data never leaves your device automatically.

If you use the game's Settings → Save Data option to generate a portable transfer code, that code is created and shown to you locally so you can copy it to another device — MOVIRA does not receive, see, or store that code.

Uninstalling the app or clearing your browser's site data for Coffee Runner permanently deletes this local save data. Because MOVIRA never holds a copy, we cannot recover it for you if you clear it yourself.

09

Account information

Coffee Runner does not have a registration, sign-in, or account system. You are never asked for an email address, username, or password to play, and the app does not integrate with any third-party login provider (such as Google Sign-In or Facebook Login).

10

Analytics

Coffee Runner does not currently use any analytics service. We checked the project's dependencies specifically for Google Analytics / Firebase Analytics, Meta/Facebook Analytics, Mixpanel, Amplitude, and similar tools — none are present. No gameplay events, session data, or usage statistics are transmitted to us or to any analytics provider.

11

Advertising

Coffee Runner does not currently display advertising. We checked for common mobile ad SDKs — Google AdMob, Meta Audience Network, Unity Ads, AppLovin, ironSource, and similar — and none are present in the project. No advertising identifier is read or used, and no ad-targeting profile is built.

If advertising is added in a future version, this section will be updated to name the ad network(s) used and how they work before that version is released.

12

Third-party services and SDKs

Based on the project's actual dependencies, Coffee Runner uses the following third-party infrastructure — and nothing else:

Google Fonts
Delivers the game's "Baloo 2" display typeface. Google's servers receive a standard web request (including IP address) to serve the font file. Used for typography only — not for tracking. See Google's Privacy Policy.
GitHub Pages
Hosts the game's static files and this website. See GitHub's Privacy Statement.

No analytics, advertising, crash-reporting, payment, authentication, or mapping SDK is present in the project (Sections 10, 11, and the confirmation note in Section 20 explain how we checked).

13

How information is used

The very limited information that ever reaches MOVIRA is used only to:

  • Reply to support emails you send us; and
  • (On your device only) adjust rendering quality and controls so the game runs well on your hardware.

We do not use any information to build advertising profiles, and we do not sell information, because we don't have any to sell.

14

How information is stored

  • Game data (progress, settings) is stored locally on your device using your browser's or WebView's on-device storage. MOVIRA has no copy and no server-side database.
  • Support emails you send us are stored in the ordinary inbox behind our support address, protected by that email provider's standard account security.
15

Data retention

Local save data persists on your device until you clear it or uninstall the app — there is no time-based expiry, because it is entirely under your control. Support emails are kept only as long as reasonably needed to resolve your inquiry, after which they may be archived or deleted in the ordinary course of managing our inbox.

16

Data sharing

MOVIRA PLC does not sell, rent, or trade personal information, and does not share it with third parties for their own marketing purposes. We have nothing to share of that kind, since we don't collect it in the first place. The only third-party involvement is the unavoidable technical delivery described in Sections 7 and 12 (hosting and font delivery), which is not MOVIRA choosing to share your data — it's how any website reaches your device.

17

Data security

Because game data stays on your device rather than passing through our systems, the main thing protecting it is your own device's security (screen lock, OS updates, and so on). Our support inbox is protected by our email provider's standard account security measures. No method of storage or transmission is ever 100% secure, so please avoid sending sensitive personal information (such as payment details or government ID numbers) in a support email — we don't need it to help you.

18

Children's privacy

Coffee Runner is a general-audience arcade game and does not require any personal information to play, from players of any age. Because the app does not collect personal information during gameplay, it does not knowingly collect personal information from children.

If a parent or guardian believes their child has sent us personal information (for example, through a support email) and would like it deleted, contact us at millionfikru6@gmail.com and we will remove it.

To confirm: this section describes actual practice, not a formal COPPA/GDPR-K certification. If you plan to declare a specific target age range or "Designed for Families" status on Aptoide or elsewhere, decide that separately and make sure it matches the app's real content and any future ad/analytics additions.

19

User rights and choices

Because there's no account and almost no data leaves your device, most control already sits with you:

  • Delete your data: uninstall the app or clear its site data/storage to permanently remove your local save.
  • Opt out of contact: simply don't email support — nothing else requires your information.
  • Ask us about it: email millionfikru6@gmail.com with any question about data you've sent us, and we'll respond.

Depending on where you live, you may have additional rights under local law regarding any information you've sent us directly; we'll honor reasonable requests relating to that information.

20

Permissions used by the Android application

The Coffee Runner source project we inspected is a browser-based game (React, three.js, and Vite) with no native Android project, AndroidManifest.xml, or app-packaging configuration (such as Capacitor) included in it. That means the exact permissions list is set by whichever tool or project was used to package the game as an Android APK for Aptoide — which is outside what we could inspect here.

To confirm before publishing: open the AndroidManifest.xml of the actual packaging project (whatever tool generated the .apk you upload to Aptoide) and list the real <uses-permission> entries here. Based on the game itself needing to load its files, internet access is virtually certain to be one of them; there may also be a network-state permission added automatically by the packaging tool. Replace this note with the confirmed list — do not submit the policy with this placeholder still in place.
